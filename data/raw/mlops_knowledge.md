# MLOps Knowledge Base

## What is MLOps?

MLOps combines Machine Learning and DevOps practices.
It manages the complete machine learning lifecycle.

## What is DVC?

DVC stands for Data Version Control.
It helps manage datasets, data versions, and machine learning pipelines.

## What is ChromaDB?

ChromaDB is a vector database.
It stores embeddings and supports semantic similarity search.

## What is RAG?

RAG stands for Retrieval-Augmented Generation.
It retrieves relevant information from external knowledge sources
and provides that information to a language model as context.

## What is FastAPI?

FastAPI is a Python web framework.
It can be used to build APIs for machine learning applications.
